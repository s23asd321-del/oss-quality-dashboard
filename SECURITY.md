# Security

If you believe you found a security issue in this project, open a private report channel if the hosting platform supports it. If only public issues are available, describe the impact at a high level and avoid including sensitive details.

Do not paste real private repository paths, raw private logs, tokens, passwords, cookies, API keys, credentials, or internal URLs into a public issue.

## Scope

- This tool is not a secret scanner.
- This tool is not a security audit.
- This tool does not guarantee that a repository is secure.
- This tool does not execute code from scanned repositories.
- This tool binds to localhost by default.

## Local Use

The default host is `127.0.0.1`. Do not expose the dashboard to a public network unless authentication, authorization, and deployment hardening are added first.
