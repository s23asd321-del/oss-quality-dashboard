# Disclaimer

`oss-quality-dashboard` provides heuristic local checks for open source project quality signals.

It is not:

- Legal advice
- A security audit
- A privacy compliance certification
- A secret scanner
- A vulnerability scanner
- A project value assessment tool
- A salary assessment tool

The score is only a heuristic reference and does not prove that a project is secure, legal, compliant, valuable, or suitable for public release.
