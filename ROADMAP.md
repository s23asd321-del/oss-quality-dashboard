# Roadmap

## v0.1

- FastAPI local dashboard
- SQLite persistence
- Built-in repository checks
- Scoring model
- Static frontend
- Markdown reports
- CLI scan command
- Tests
- Docs
- Docker

## v0.2

- Adapter interface for existing CLI tools
- Richer Markdown checks
- Better report filtering
- Import/export scan results

## v0.3

- Optional GitHub Actions usage guide
- Scheduled local scans
- HTML report export

## v0.4

- Optional authentication for non-local deployment
- Postgres support

## v1.0

- Stable API
- Stable DB schema
- Documented security model
- Documented compatibility policy

## Not Planned For The First Version

- GitHub API calls
- Network access from scanner code
- Login system
- Multi-user support
- Cloud sync
- AI suggestions
- Automatic fixes
- Modifying scanned repositories
- Executing scanned repository code
- Installing scanned repository dependencies
- Real secret scanning
- Vulnerability scanning
- Legal compliance judgments
- Salary or personal ability scoring
- Report uploads
